# Label-Efficient Representation Learning for Computer Vision using Self-Supervised Deep Learning

## Overview

This is an M.Tech research project focused on investigating how self-supervised learning (SSL) can improve visual representation learning when labeled training data is limited.

## Research Objective

To study whether deep learning models can learn useful visual features from unlabeled images and achieve good performance on downstream computer vision tasks using a small amount of labeled data.

## Proposed Methodology

1. Dataset selection and preprocessing
2. Self-supervised representation learning
3. Fine-tuning with limited labeled data
4. Supervised baseline implementation
5. Performance evaluation and comparison

## Candidate Technologies

- Python
- PyTorch
- Vision Transformers (ViT)
- Masked Autoencoders (MAE)
- Scikit-learn
- Jupyter Notebook

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Label efficiency
